# Multifactor Authentication

Authentication is the process of confirming the identity of a user or device prior to authorising access to confidential information or valuable resources.
In this phase, we calculate σi using reproduction function that uses both Bi and θi as inputs. At the same time, a session key Sk is created and checked by both sides to ensure it’s correct. If any data appears wrong or damaged during this phase, we abort the process. Otherwise, it successfully generates the session key Sk and confirms the identity of Ui.
