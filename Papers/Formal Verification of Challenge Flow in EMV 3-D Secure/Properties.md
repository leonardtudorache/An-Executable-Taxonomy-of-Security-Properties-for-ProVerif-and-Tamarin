# Confidentiality

For confidentiality, we can verify whether an attacker can obtain given information using the reachability verification (secrecy) and whether an attacker can guess given information using an off-line search of candidates when the length of the information is short (off-line dictionary attack resistance) using the observational equivalence verification.

# Authenticity

For authenticity, the correspondence assertion verification is used to check whether or not, between entities communicating using the same authentication information, when an event accepted by the receiver occurs, an event sent by the corresponding sender always occurs in advance (spoofing attack resistance), and whether these events are in a one-to-one relationship (replay attack resistance).
